# Security & safety

A way for a child to get around a protection this project designs — filter, time limit,
allowlist, account boundary — is a security issue.

**Report it privately:** [open a security advisory](https://github.com/markcuda/omarchy-kids-mode/security/advisories/new). Include the
steps, and the skill level needed (any kid / curious 10-year-old / Linux-savvy teen / physical
access). We aim to acknowledge within 7 days and agree a disclosure timeline with you.

Kids who find bypasses are welcome to report them — through a parent, please. Credit goes to the
parent's handle.

Already-public or theoretical weaknesses can go straight to a normal issue. No working bypass
recipes in public docs until a mitigation exists. We never claim anything is unbypassable.

Nothing this project ships may send data about a child off the machine. Vulnerabilities in
Omarchy itself go to security@omarchy.org.
