# Gamification, Guided Learning, and the "Learning Pack" Model (Learn with Omy)

_Research report · Omarchy Kids Mode · 2026-09-01 · status: draft_

## TL;DR

- **Duolingo is two systems wearing one owl.** A learning core (bite-size lessons, immediate feedback, adaptive difficulty via Birdbrain, spaced review via half-life regression, CEFR-aligned objectives) sits under a retention layer (streaks, Energy, XP, gems, leagues, quests, badges, bandit-tuned notifications). Duolingo's own papers optimise the retention layer for *engagement*: HLR "improved daily student engagement by 12%" [S1]; the notification bandit's objective is lesson completion [S23]; streaks "tap into loss aversion" [S7]. Learning is measured separately, through a proxy metric ("Time Spent Learning Well") because "they can't learn if they churn" [S26].
- **The learning core is well evidenced, including for 5–12-year-olds.** Spacing (839 assessments; optimal gap grows with the retention interval) [S38]; spacing in 5–7-year-olds improves generalisation [S42]; retrieval practice in 4th graders, d = 0.48–0.64 [S41]; interleaving in 7th graders, d = 0.42/0.79 [S43]; practice testing and distributed practice "benefit learners of different ages" [S44]. Immediate feedback wins in classroom studies [S45], though Grade 6 children learned vocabulary better with *delayed* feedback in one lab study [S46].
- **The retention layer is not learning science, and children are the group it harms most.** Tangible rewards "tended to be more detrimental for children than college students" [S53]; gamification's motivational effect is weakest in primary school (g = 0.31 vs 1.02 secondary) and larger on extrinsic than intrinsic motivation [S57]; effects collapse over time (interventions under 1 h, ES 1.57; multi-year, ES −0.20) [S58]; a 5th-grade field study found badges vs leaderboards made no difference, attributing gains to "holistic design and novelty" [S59]. Report 07 §4's rules (mastery-only rewards; no streaks, loss timers, variable rewards, push nags) stand.
- **Duolingo itself drops the retention layer for young children.** Its Literacy app (ABC, ages 3–8) has "in lieu of a formal streak … a daily joke", no leaderboard or shop described anywhere in its documentation (inferred from silence), an adult-selected starting level, and a curriculum pinned to Common Core K–2 foundational reading skills [S11][S13]; under-13 accounts on the main app get private profiles with social features restricted (SEARCH-ONLY) [S36]. That is the precedent for Kids Mode: keep the loop, drop the hooks.
- **"Same loop, different subject" works only when the subject is re-modelled, not re-skinned.** Math needed new "knowledge components", bespoke exercise types and thousands of animations ("we can't represent all content in the same way") [S16]; the volunteer Incubator (2013–2021, 1,000+ contributors) was closed because "strict timelines and specific templates" could not be imposed on volunteers and the courses now earn money [S4]. Lesson: packs need a strict schema and a review gate, or they need a paid content team.
- **Prior art already gives us the pack format.** Kolibri (MIT, offline-first) ships content as *channels* of topic/resource nodes with licence, language and per-exercise mastery models (`m_of_n`, `num_correct_in_a_row_N`, `do_all`), importable by token, USB or LAN [S61][S66][S70]; Endless Key is an open-source Kolibri plugin that adds "content packs with extra metadata" [S89][S90]; Anki's `.apkg` is the proof that community decks work when the shared artefact is *content only* with "scheduling information" stripped [S78][S80]; GCompris declares each activity's `difficulty`, `section`, `goal`, `prerequisite`, `manual`, `levels` in a data file [S72]. Pack = data; engine = code. Same rule Omarchy applies to themes (report 01 §4).
- **Tutoring evidence supports a deterministic tutor, not a chatbot.** ITS effect d = 0.76 vs human 0.79 [S92]; median 0.66 SD across 50 evaluations [S93]; ASSISTments' immediate feedback + error-specific hints raised 7th-grade standardised scores (g = 0.18) [S94]. LLM tutors without guardrails *harmed* unaided exam performance in high school; "teacher-designed hints instead of giving away answers" removed the harm [S99]. No RCT of LLM tutors with under-13s was found. For Kids Mode: pack-authored hints and worked examples first; an offline LLM, if ever, only as a re-phraser of pack-authored text under report 07 §5's rules (no persona, no memory, off by default, 8+).
- **Therefore:** a learning pack must contain objectives, items with feedback and hints, mastery criteria, worked examples, age band, assets and a licence, and must not contain code, reward tuning, network calls or anything about the child. The engine owns scheduling, mastery tracking, mastery badges, the parent view and local-only progress. Workstreams LRN-01…LRN-10 in §7.

## 2. What Duolingo actually does

Method note. Everything below is from Duolingo-owned sources (blog, research papers, whitepapers, efficacy reports) unless marked; secondary sources are labelled. SEC filings (10-K, shareholder letter) returned 403 to the fetcher and are SEARCH-ONLY [S32][S33]. Dates are the post dates.

| Mechanic | What it is | Duolingo's stated rationale / evidence | Learning-science basis | Under-13 verdict (report 07 §4 rules) |
| --- | --- | --- | --- | --- |
| **Streak** (+ freeze, repair, milestones, Friend Streak) | Days in a row with ≥1 lesson; freezes bought with gems; milestone animations | "We tap into loss aversion" (2022) [S7]. Streak Wager test +14% day-7 retention; Weekend Amulet +4% return (2017) [S8]. 7-day streak → 3.6× more likely to complete course; milestone animations +1.7% D7 retention; doubling freezes +0.38% DAL [S7]. Former CPO: 10-day streak "reduced substantially" drop-off [S6]. FY2025: ~43 M DAU with 7+-day streak, ~15 M with 365+ (SEARCH-ONLY) [S32]. Whitepaper cites Silverman & Barasch 2022 [S11] | Habit-formation cue research is real, but the mechanism used is loss aversion, not learning. Duolingo's Literacy app omits it for 3–8s [S11] | **Drop.** Report 07 §4: no streaks, no loss-aversion timers; DSA guidance says off by default for minors |
| **Hearts → Energy** (2025) | Hearts: −1 per mistake, 5 then locked out. Energy: a daily budget spent per exercise, regained by consecutive correct answers, refilled by ads/gems, unlimited for subscribers | "Each mistake cost 1 heart … This was not the most effective way to support learning"; beginners "2X more likely to run out of hearts mid-lesson"; Energy "helps more learners complete lessons" (2025-07-03) [S9] | Punishing errors contradicts error-tolerant retrieval practice; Duolingo's own admission | **Drop.** Mistakes must be free (report 07 §4 "Oops, never wrong"). No session caps tied to errors; time budgets are the parent's, not the game's |
| **XP, gems, XP boosts, shop** | Points per lesson; currency for freezes/boosts/timers | Whitepaper: "frequent rewards … keep the brain engaged"; reward after every exercise (sound + animation) and after each session (XP, currency, unlocked material) [S11] | Deci et al. 1999: engagement- and completion-contingent tangible rewards undermine intrinsic motivation, more so in children [S53] | **Adapt.** Keep the *immediate* confirmation (sound, tick) which is feedback, not reward. No currency, no shop, no buyable anything |
| **Leagues / leaderboards** | Weekly cohorts ranked by XP, promotion/demotion across 10 leagues; opt-out via profile visibility | "A little competition worked for a lot of learners" (2023) [S25]. Former CPO: leagues +17% learning time, tripled 1 h/day×5 users [S6]. Whitepaper cites Landers et al. 2017 [S11]. Under-13 accounts: social features restricted (SEARCH-ONLY) [S36] | Sailer & Homner: social interaction moderates *behavioural* outcomes [S55]; but K-12 meta-analysis shows the weakest motivational effect in primary school [S57]; 5th-grade study: leaderboards ≈ badges ≈ novelty [S59] | **Drop** (strangers) / **Adapt** (family). No ranking of children. A shared "what we learned this week" family board is defensible; it is relatedness (SDT), not competition |
| **Daily quests / Friend quests** | Three daily tasks (XP, correct answers, minutes); weekly co-op quests | "Even more reason to show up every day" (SEARCH-ONLY snippet, blog) | None specific; it is a daily-login bait | **Drop.** Report 07 §4: no daily-login bait |
| **The Path** (Nov 2022) | Linear sequence replacing the skill tree; skills interspersed; stories and practice inline; "one path level equals one crown level" | Spaced repetition: "more effective to space out practice … than to cram"; mixes new and review [S5] | Spacing [S38], interleaving [S43], guided sequencing for novices (CLT; Sweller 2019 review SEARCH-ONLY [S50]) | **Keep.** A linear, visibly finite path with interleaved review is right for 5–12s. Parent confirms level-ups (report 07) |
| **Crown / mastery levels, Legendary** | Repeat a unit at rising difficulty; "Legendary" = error-free timed pass | Progress visibility; whitepaper: "showing progress on a learning path" [S11] | Mastery learning (Bloom 1984, ~1 sigma) [S47]; Cognitive Tutor's mastery gating [S95] | **Adapt.** Mastery levels yes; timed error-free "Legendary" no (time pressure + loss) |
| **Birdbrain** (2020) | ML model of learner knowledge × exercise difficulty; Session Generator picks exercises "at just the right difficulty" | A/B tests: learners "learn more" and are "more likely to continue"; >20% of lessons personalised by Oct 2020 [S3] | Desirable-difficulty and ZPD reasoning [S48]; Bloom/ITS knowledge tracing tradition [S92][S93] | **Adapt.** A tiny local scheduler (per-item difficulty + per-child accuracy) gives most of the benefit without a model or telemetry |
| **Half-life regression** (2016) | Trainable spaced-repetition model estimating each item's memory half-life from lag and history | "reducing error by 45%+ compared to several baselines"; deployed, it "improve[d] Duolingo daily student engagement by 12%" [S1] | Spacing + lag effect (Ebbinghaus [S39]; Cepeda [S38]) | **Keep** the scheduling idea; **drop** the engagement objective. A fixed expanding schedule (Leitner/Pimsleur style, which HLR beat by 45% on *prediction*, not on learning) is adequate offline |
| **Bite-size lessons** | 2–5 min sessions; 2025: "smaller chunks" for intermediate learners [S28] | "Bite-sized lessons … feel more like a game"; decreasing "perceived effort" [S11] | Attention span 5–9 rises then plateaus ~10 (report 07 §1) | **Keep.** 3–5 items per session for Guided band; parent time budget bounds the day |
| **Immediate feedback** | Right/wrong with explanation after every exercise; end-of-lesson mistake review | Whitepaper cites Butler et al. 2008; "instantaneous feedback then either confirms or denies … predictions" [S11] | Classroom meta-analysis favours immediate [S45]; one lab study: Grade 6 children did better with delayed [S46] | **Keep** immediate correctness + a short *why*; add an end-of-session re-test of misses (delayed feedback + retrieval) |
| **Notifications** ("guilt-trip owl") | Bandit-optimised reminders; ~200 M reminders/34 days studied; novelty decays and is modelled with the same forgetting curve as vocabulary | Goal: reminders that get learners to "complete a lesson" [S23]. Handbook: "User trust matters more than immediate gains" (via MtP) [S29] | None | **Drop.** No push. The only reminder is the parent's |
| **Stories / DuoRadio** | Narrative reading/listening in the path; "100,000+ new DuoRadio episodes" 2025 [S28] | "flexible listening skills"; entertainment [S5] | Narrative framing moderates behavioural outcomes ("game fiction") [S55]; ABC uses a "mission to help … characters collect books" [S11] | **Keep.** A pack may carry a story frame; the engine must not add a persona (report 07 §5) |
| **Duolingo Max** (Mar 2023, GPT-4): Explain My Answer, Roleplay, Video Call (Sep 2024) | AI explanation of a mistake (free for all since the 2026-01-01 post [S20]); scripted-scenario chat; unscripted video call with "Lily" who adapts to level and withholds grammar corrections | Scenarios and initial prompts "written by human curriculum experts"; outputs reviewed; error reporting [S18]. Video Call post cites no efficacy [S19]; a 2025 whitepaper on Video Call exists (SEARCH-ONLY) | LLM tutor evidence, §6 | **Drop** Roleplay/Video Call (persona + online). **Adapt** Explain-My-Answer as pack-authored explanations; LLM re-phrasing only under §6 rules |
| **Duolingo ABC** (Literacy app, ages 3–8; iOS 2020, Android 2022) | Nine "buildings" (levels) with unit steps; Pre-K/K levels 1–4, 1st grade 5–8, 2nd grade 9; phonemic awareness → phonics → sight words → stories [S13] | Curriculum "based on the foundational skills for reading outlined in the Common Core … kindergarten, first grade, and second grade"; "in lieu of a formal streak the Literacy app provides a daily joke"; adults pick a starting level; per-exercise sound/colour/motion feedback; hints; "mission to help our app characters collect books" [S11]. EDC 2022: n = 105, ages 4–5, 9 weeks, single-sample pre/post, PALS-K gains significant, hours-of-use predicted post-test; no control group (ESSA Tier 3) [S14] | Standards-mapped objectives; scaffolded levels | **Keep as the model.** This is Duolingo's own answer to "what survives for under-8s": objectives, levels, feedback, delight; no streak, no league, no shop |
| **Duolingo Math & Music** (in-app Oct 2023) | Same shell; streak, XP, quests and leagues shared across subjects [S15] | Math: language courses use uniform text "knowledge components"; "For math … we can't represent all content in the same way"; bespoke exercise types (build quadrilaterals, cut pies), thousands of visuals, moved to Rive animations [S16]. Music: rhythm, note names, on-screen keyboard [S17] | Domain modelling is the hard part, not the loop | **Keep** the principle: the pack schema must allow subject-specific *item types*, not just flashcards |
| **Incubator / Contributor program** (2013–2021) | Volunteers built courses in a web tool; 1,000+ contributors, dozens of courses | Ended 2021-03-10: "Duolingo now makes money from our courses"; "strict timelines and specific templates … cannot and should not be applied to volunteer Contributors"; $4 M award; paid Course Specialist roles [S4] | n/a | **Adapt.** Community authoring needs (a) a template the tool enforces, (b) a review gate, (c) honest expectations about volunteer cadence |
| **Achievements / badges** (redesign Dec 2023) | Badges for streak lengths, XP in a day, perfect lessons, best league finish, adding friends, "night owl" [S27] | "Learning something new isn't easy – and deserves celebration" [S27] | Badges alone: no effect beyond novelty in 5th graders [S59] | **Adapt.** Badges only for *mastery events*, visible offline, never expire (report 07 §4). None for time, days, friends or hours |
| **Duolingo Score, Chess ELO** (2025) | Proficiency score shareable to LinkedIn; PvP chess [S28] | Progress externalised | Fine for adults | **Drop** sharing; the parent view is the only audience |

Two facts frame the whole table. First, Duolingo's efficacy claims are about *adults* learning *languages* on CEFR-aligned paths ("five sections … as much as five semesters" [S22]; four-question framework: engagement, mastery, application, proficiency [S21]); no efficacy study of Math or Music was found, and the only child study (ABC) has no control group [S14]. Second, Duolingo built TSLW precisely because engagement and learning diverge: "the number of completed lessons was the strongest predictor of learning gains", path lessons weigh 1.0 and other activities 0.5, and non-learning activities are kept because "they can't learn if they churn" [S26]. The under-13 product without those activities is a clean subtraction.

What Duolingo measures versus what it optimises (all from Duolingo-owned sources):

| Layer | Objective named in the source | Evidence type | Who it is measured on |
| --- | --- | --- | --- |
| Spaced review (HLR) | Recall prediction error; then "daily student engagement" in the operational study [S1] | Offline model fit + A/B | Adult language learners |
| Birdbrain | "learn more" and "more likely to continue learning" [S3] | A/B tests, numbers not published | Adult language learners |
| Streak features | Day-7 retention, DAL, course completion odds [S7][S8] | A/B tests | Adult language learners |
| Notifications | Lesson completion after a reminder [S23] | Bandit online learning | All users |
| Leagues | Learning time, highly-engaged-user count [S6] | A/B tests (ex-CPO account) | All users |
| Energy | "helps more learners complete lessons" [S9] | A/B tests | Free-tier users |

Verified pattern: every retention mechanic is validated on retention metrics; learning is validated separately and only for adults. Nothing in the fetched corpus shows a streak, league or notification improving a *learning* outcome.

## 3. The learning science underneath

| Principle | Canonical evidence (fetched) | Holds for 5–12? | Design consequence |
| --- | --- | --- | --- |
| **Spacing / lag** | Cepeda et al. 2006: 839 assessments, 317 experiments, 184 articles; "the ISI producing maximal retention increased as retention interval increased" [S38]. Murre & Dros 2015 replicated Ebbinghaus's curve (70 h, 20 min–31 days) [S39] | Yes. Vlach & Sandhofer 2012: 5–7-year-olds, spaced science lessons raised generalisation for simple and complex concepts [S42] | Engine keeps a per-item due date; review gaps expand (days → weeks). No need for a trained model |
| **Retrieval practice** | Roediger & Karpicke 2006: restudy better at 5 min, testing "substantially greater retention" at 2 days and 1 week; "Testing is a powerful means of improving learning, not just assessing it" [S40] | Yes. Karpicke, Blunt & Smith 2016: 88 4th-graders, retrieval > restudy (55 vs 44%; 42 vs 28%), d = 0.48–0.64, independent of reading/processing speed [S41] | Every item is a question the child answers, not a screen the child reads. Re-test misses at session end |
| **Interleaving** | Rohrer, Dedrick & Stershic 2015: 126 7th-graders, 3 months; d = 0.42 immediate, 0.79 delayed [S43]. Dunlosky et al. 2013 rate it "moderate" utility [S44] | Yes for 12–13; extrapolated below | Mix item types within a session once ≥2 skills exist (the Path's "interspersed" skills [S5]) |
| **Immediate feedback** | Kulik & Kulik 1988: 53 studies; "applied studies using actual classroom quizzes … found immediate rather than delayed feedback to be more effective; experimental studies … indicate the opposite" [S45] | Mixed. Metcalfe, Kornell & Finn 2009: Grade 6 children, delayed > immediate > none on vocabulary, even with lag to test controlled [S46] | Immediate *correctness* (a child cannot wait), plus a delayed *re-ask* of misses. Both, not either |
| **Mastery learning** | Bloom 1984 "2 Sigma": tutoring vs conventional, and mastery-learning techniques as the group method to close the gap [S47] (ERIC abstract; the 2σ/1σ magnitudes are the paper's headline, not re-verified here) | Bloom's data are school-age | Do not advance on time; advance on demonstrated mastery (m-of-n or n-in-a-row) |
| **Desirable difficulties** | Bjork lab: spacing, testing, generation, interleaving, varying conditions "impede performance during training but … yield greater long-term benefits"; combinations are not additive (spacing × variation can hurt) [S48] | Adult lab evidence; use with care | Pick two (spacing + retrieval). Do not stack novelty on top |
| **Cognitive load / worked examples** | Sweller 1988 (metadata verified only) [S49]; Sweller, van Merriënboer & Paas 2019 review (SEARCH-ONLY, cookie wall) [S50] | Novices benefit most from worked examples; the "expertise reversal" is inferred from the literature, not re-verified | Packs carry a worked example per skill; the engine shows it *before* first retrieval and *on* second miss |
| **Scaffolding / ZPD** | Wood, Bruner & Ross 1976 (metadata verified; abstract elided) [S51]; Duolingo Literacy app: hints such as highlighting initial letters, levels "gradually scaffold" [S11] | The original study was with pre-schoolers (not re-verified this round) | Hints are tiered and pack-authored; the engine reveals them in order |
| **Self-determination theory** | Autonomy, competence, relatedness; intrinsic motivation "for its own sake"; Cognitive Evaluation Theory: rewards and controls affect intrinsic motivation [S52]. Deci, Koestner & Ryan 1999: 128 experiments; engagement-, completion- and performance-contingent tangible rewards undermine intrinsic motivation; positive feedback enhances it; "tangible rewards tended to be more detrimental for children than college students" [S53] | Yes, explicitly | Feedback yes, tangible/currency rewards no. Autonomy = the child picks the pack; competence = visible mastery; relatedness = parent sees and says so |
| **Gamification (general)** | Hamari, Koivisto & Sarsa 2014: positive effects "greatly dependent on the context … as well as on the users" [S54]. Sailer & Homner 2020: g = 0.49 cognitive (k = 19), 0.36 motivational (k = 16), 0.25 behavioural (k = 9); game fiction and social interaction moderate behavioural outcomes; mechanisms "partially unclear" [S55]. Huang et al. 2020 (SEARCH-ONLY) [S56] | Partly | Narrative frame and co-operation are the two elements with evidence; points/badges/leaderboards as such are not |
| **Gamification (children)** | Kurnaz & Koçtürk 2025, K-12 motivation, 31 studies: g = 0.65 overall; extrinsic (0.71) > intrinsic (0.64); **primary school g = 0.31**, secondary 1.02, high school 0.82 [S57]. Kim & Castelli 2021, 18 studies: <1 h interventions ES 1.57, multi-year ES −0.20; badges, leaderboards, points most used [S58]. Mohammed et al. 2024: 30 5th-graders, badges vs leaderboards no difference; "holistic design and novelty" [S59] | Yes, and the youngest benefit least | Expect a novelty bump that fades. Design the loop to work with zero game layer; add delight, not hooks |

Age split, plainly: spacing, retrieval and immediate-correctness feedback have direct evidence in 5–10-year-olds [S41][S42]; interleaving and delayed-feedback benefits are shown at grades 6–7 [S43][S46]; desirable-difficulty interactions, CLT expertise reversal and most gamification meta-analytic detail are adult or mixed-age evidence. Report 07 §1's bands (pre-operational under 7; concrete-operational 7–11) mean the Guided band should get short, concrete, single-skill sessions and the Independent band can take interleaving and delayed re-asks.

## 4. Duolingo as a subject-agnostic engine

| Component | Transferred to Math/Music/Chess unchanged? | Source |
| --- | --- | --- |
| Streak, XP, quests, leagues, achievements | Yes, by accounting: "Any lesson you complete in Duolingo will count towards your streak" | [S15][S17][S28] |
| Path shell (units, levels, guidebook) | Yes | [S15] |
| Session generator / Birdbrain | Not stated for Math; the Math post describes a separate content pipeline | [S16] |
| Item types | No: bespoke interactive types per concept, thousands of visuals | [S16] |
| Objective schema | No: CEFR for language, Common Core for literacy, none published for Math/Music | [S11][S21] |
| Efficacy evidence | No: none found for Math or Music | [S21][S22][S35] |

- **What transfers.** The shell (path, session generator, feedback, XP/streak accounting) was reused for Math and Music with no change: "Any lesson you complete … will count towards your streak"; XP, boosts and most quests are cross-subject [S15][S17]. Chess (2025) reused it again [S28]. Inferred: the *retention* engine is subject-agnostic by construction because it counts sessions, not knowledge.
- **What did not transfer.** The *learning* engine assumes uniform knowledge components (words, characters, phrases as text). Math broke that: "we can't represent all content in the same way, and how we teach depends on the context"; addition, perimeter and geometry each needed distinct visual exercise types, and the count of bespoke visuals "quickly grows into the thousands" [S16]. Verified consequence: a pack schema needs typed items (choice, input, ordering, drag-to-target, key-press) and per-subject media, not one card type.
- **The objective schema.** Language courses are pinned to CEFR levels (A1–C2), which is what the efficacy framework measures against [S21]; the Literacy app is pinned to Common Core K–2 reading foundations [S11]; Khan Kids to Head Start ELOF + Common Core [S60]; PBS KIDS built a math framework "mapping key building-block skills" before commissioning games [S77]. Every serious children's product names an external objective list first. "Learn the Omarchy machine" has none, so the first pack must *publish* its own (report 07's L1→L3+ capability ladder is the obvious skeleton).
- **Why the Incubator closed.** Not quality per se: money ("Duolingo now makes money from our courses") and process ("strict timelines and specific templates … cannot and should not be applied to volunteer Contributors") [S4]. Course creation is now internal and paid. Inferred lesson for a hub of volunteer packs: the template must be *enforced by the tool* (schema validation, lint, preview) so consistency does not depend on deadlines, and the community should expect packs to be small and slow rather than course-sized.
- **How Duolingo authors now.** "hundreds of experiments, or A/B tests, each week" [S11], CEFR-based unit design, human-written AI scenarios reviewed for "accuracy and tone" [S18]. None of this is available to an offline kids' engine; what is available is the *front* of that pipeline: a written scope-and-sequence (ABC publishes one [S13]) and per-unit objectives.

## 6. Tutoring and "agentic tutoring" evidence

| Study | Population | Intervention | Effect | Source |
| --- | --- | --- | --- | --- |
| Bloom 1984 | School-age | One-to-one tutoring; mastery learning | "2 sigma" headline; mastery learning as the group substitute | [S47] |
| VanLehn 2011 | Mostly college and secondary | Human vs ITS vs answer-based CAI | d = 0.79 / 0.76 / 0.3 | [S92] |
| Kulik & Fletcher 2016 | 50 evaluations, K-12 and college | ITS vs conventional | median +0.66 SD; smaller on standardised tests | [S93] |
| Roschelle et al. 2016 | 2,850 7th-graders, Maine | ASSISTments homework: immediate feedback, hints, teacher reports | g = 0.18 on standardised test; low achievers gain most | [S94] |
| WWC 2016 | 12,182 students, grades 8–13 | Cognitive Tutor Algebra I | mixed, +4 percentile avg (−7 to +19) | [S95] |
| Bastani et al. 2025 | High school maths | GPT-4 tutor, with/without guardrails | practice up; unaided exam down unless hints-only | [S99] |
| Kestin et al. 2025 | College physics | AI tutor vs active learning | AI tutor higher, less time | [S100] |
| De Simone et al. 2025 | Senior secondary, Nigeria | GPT-4 in pairs, supervised, 6 weeks | +0.31 SD overall, +0.23 English | [S101] |
| Khanmigo | Elementary to college (online) | Socratic LLM tutor with parent visibility | No effect sizes on the page | [S96] |

None of the nine rows is an under-13 offline setting; the two rows nearest our age range (ASSISTments, Cognitive Tutor) are deterministic hint-and-mastery systems.

- **Human vs machine.** Bloom 1984 set the target (one-to-one tutoring vs group instruction; mastery learning as the group remedy) [S47]. VanLehn 2011 found human tutoring d = 0.79, ITS d = 0.76, answer-based CAI d = 0.3, concluding ITS "were nearly as effective as human tutoring" [S92]. Kulik & Fletcher 2016: 50 controlled evaluations, median +0.66 SD (50th → 75th percentile); much smaller on standardised than locally developed tests, and near zero when the tutor was poorly implemented [S93].
- **Deterministic tutors that work without LLMs.** ASSISTments: 2,850 7th-graders, 43 Maine schools, RCT; tool "provides timely feedback and hints to students as they do homework" plus teacher reports; +0.18 SD on the end-of-year standardised test; lowest prior achievers gained most [S94]. Cognitive Tutor (model tracing, hints, mastery): WWC 2016 rates Algebra I "mixed effects" (+4 percentile points average, range −7 to +19, 5 studies, 12,182 students, grades 8–13) and Geometry "potentially negative" [S95]. Inferred: hints-plus-mastery is the mechanism with evidence; effect sizes in the field are modest and depend on alignment between what is taught and what is tested.
- **LLM tutors (2024–2025), none under 13.** Bastani et al., PNAS 2025, high-school maths RCT: GPT-4 "improves performance during practice sessions" but students "may underperform when access to AI is subsequently removed"; "asking the AI tutor to provide teacher-designed hints instead of giving away answers, can mitigate these negative effects" [S99]. Kestin et al., Scientific Reports 2025: college physics, AI tutor beat in-class active learning in less time [S100]. World Bank Nigeria 2025: senior secondary, six weeks, pairs, teacher-supervised, +0.31 SD overall and +0.23 SD English; largest effects for girls and higher-baseline students [S101]. Duolingo's own Video Call cites no efficacy in its launch post [S19]. No RCT with children under 13 was found; that absence is itself a finding.
- **Khanmigo's published guardrails (for context, online product).** Socratic: "guides learners to find the answer themselves"; "elementary school through college"; parents "view the history of your children's interactions" and get "alerts for flagged content"; $4/month, up to 10 children under 18 [S96]. Khan's 2025 Responsible-AI framework lists learner autonomy, privacy, transparency and accountability among nine principles [S97]. The support-centre pages on safety features and under-13 login returned 403 (SEARCH-ONLY) [S98][S102].
- **Conclusion for an offline under-13 tutor** (applying report 07 §5: no persona, no memory, off by default, 8+, offline). What a tutor layer may do: (1) surface the pack's tiered hints in order; (2) show the pack's worked example on the second miss; (3) re-phrase a pack-authored prompt or explanation in simpler words; (4) read text aloud. If a local LLM is ever used for (3), it is constrained to re-wording *pack text*, never generating new facts, with no chat surface, no memory, session-scoped, and its output labelled as re-phrased. What it must not do: answer for the child (Bastani's harm) [S99]; converse; praise or nag; remember the child; call the network; exist for the Guided band (under 8). The deterministic hint + worked-example + mastery loop is the evidence-backed tutor; the LLM is optional polish.

## 7. Implications & recommendations

**(a) Mechanics for Kids Mode**

| Keep | Adapt | Drop |
| --- | --- | --- |
| Linear path with interleaved review [S5][S43]; bite-size sessions [S11]; immediate correctness + short why [S45]; end-of-session re-ask of misses [S40][S46]; spaced due-dates [S38]; mastery gating (m-of-n / n-in-a-row) [S47][S70]; story frame supplied by the pack [S55][S11]; delight (sound, motion, characters) [S12] | Adaptive difficulty → local item-difficulty × child-accuracy heuristic [S3]; badges → mastery events only, offline, permanent (report 07 §4) [S59]; leaderboard → family "what we learned" board, no ranks [S57]; Explain-My-Answer → pack-authored explanations [S20]; starting level → parent-selected as in ABC [S11]; Legendary → untimed mastery retry | Streaks, freezes, wagers [S7][S8]; hearts/Energy [S9]; XP, gems, shop, boosts [S53][S76]; daily/friend quests; strangers' leagues [S25]; push notifications [S23]; Roleplay/Video Call personas [S19]; share-to-social scores [S28] |

**(b) What a learning pack MUST contain** (per §3–§5)

1. `manifest`: id (reverse-domain, never `omarchy.*`, cf. report 01 §5), title, version, author, licence (SPDX; default CC BY 4.0 as H5P does [S84]), language, **age band(s)** (report 07 bands), subject, estimated sessions, `schemaVersion`.
2. **Objectives**: an explicit, numbered list; each mapped to an external framework if one exists (CEFR, Common Core, ELOF) or to the pack's own published scope-and-sequence (as ABC publishes one [S13]).
3. **Units → skills → items**, each item: type (single-select, multi-select, input, order, drag-to-target, key-press/desktop-action), prompt, answer(s), **corrective feedback text** for common wrong answers, 1–3 **tiered hints**, difficulty (1–6 like GCompris [S72]), prerequisite skill ids, `mastery_model` per skill using Kolibri's names [S70].
4. **Worked example** per skill (text + optional image/audio) shown before first retrieval and on second miss.
5. **Assets**: images, audio (pre-readers need narration: report 07 §4), all local, all licensed in the manifest.
6. Optional **story frame**: characters and a mission, as data (names, lines, art).
7. An **authoring guide** and a `validate` command that rejects anything outside the schema (the Incubator's "template" problem solved by tooling [S4]).

**MUST NOT contain**: executable code (QML, JS, shell), reward or timing parameters, network endpoints, telemetry, fonts/binaries, any reference to a specific child, or a persona that speaks in first person about feelings (report 07 §5). Precedent: Omarchy strips code from third-party themes so "installing someone's theme should change what your desktop looks like, never what it runs" (report 01 §4); packs get the same rule.

Pack anatomy v0 (proposal; opinion, to be settled by LRN-01):

| Path in pack | Contents | Precedent |

| `pack.json` | id, title, version, author, licence, language, age bands, subject, `schemaVersion` | H5P `h5p.json` [S83]; Omarchy plugin `manifest.json` (report 01 §5) |
| `objectives.md` | Numbered objectives with framework mapping; the published scope-and-sequence | ABC scope & sequence [S13]; PBS framework-first [S77] |
| `units/NN-<slug>.json` | Skills → items (type, prompt, answers, feedback per wrong answer, hints[1..3], difficulty, prerequisites), `mastery_model` per skill | Kolibri exercise nodes [S68][S70]; GCompris `ActivityInfo` fields [S72] |

| `assets/` | Images, audio narration; every file listed with licence in `pack.json` | Anki media bundling [S78]; Kolibri licence-per-node [S67] |

| absent by rule | `*.qml`, `*.js`, `*.sh`, URLs, telemetry, reward tuning, child data | Omarchy theme code-stripping (report 01 §4) |

**(c) What the engine owns**: scheduler (expanding intervals, per-item due dates); session generator (3–5 items, interleaved once ≥2 skills are open); mastery tracker; the only badges (mastery events); hint/worked-example reveal order; the parent view (progress per objective, misses, time; local HTML, no cloud); level-up confirmation gate (child demonstrates, parent confirms); local-only progress log in xAPI-like statements [S86]; pack install/validate/remove; a library shelf ("Steam for packs") that reads manifests. The engine never nags, never counts days, never ranks, never phones home. First-party home: a Quickshell `overlay`/`panel` plugin (report 05 §5), with packs under `~/.config/omarchy/...` as data only.

**(e) Open questions for the community**
