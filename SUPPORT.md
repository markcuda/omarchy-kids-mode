# Support

- **Questions about this project / the process** → GitHub Discussions (Q&A) or the kids-mode channel on the
  Omarchy Discord (invite on omarchy.org).
- **Questions about Omarchy itself** → Omarchy's own channels (`#omarchy-help` on Discord, the manual at
  omarchy.org/manual). We're a satellite project and can't support upstream.
- **A safety bypass** → `SECURITY.md` (private reporting first).
- **Nothing here works yet** — that's correct. We're in Phase 0 (research and alignment). See `ROADMAP.md`.
